# Система управления расписанием (Schedule Manager)

Учебный проект на Java для управления расписанием занятий.
Позволяет добавлять пары, проверять конфликты (по аудиториям, преподавателям и группам),
подсчитывать нагрузку преподавателей и выводить расписание по различным критериям.

## 📋 Возможности

- **Добавление занятий** с автоматической проверкой конфликтов:
  - одна аудитория не может быть занята в одно и то же время;
  - преподаватель не может вести две пары одновременно;
  - группа (или подгруппа) не может быть занята в одно и то же время.
- **Подсчёт академических часов** для конкретного преподавателя.
- **Вывод расписания** по группе, преподавателю или аудитории.
- **Безопасное добавление** занятия с обработкой ошибок (без падения программы).
